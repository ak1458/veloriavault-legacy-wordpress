## Scope and status

This is a legacy full-platform tree rather than a small reusable theme package. Do not deploy the archived application as a current, maintained storefront. Reconstruct a disposable local environment only after reviewing its platform/plugin versions, database requirements, credentials, and third-party licenses.

## Inspect the source

The repository’s default branch is the source of truth for the files currently available. Inspect [history](https://github.com/ak1458/veloriavault-legacy-wordpress/commits) to understand changes over time. Do not treat an archive label as a build or runtime validation.

Top-level source areas: `wp-admin/`, `wp-content/`, `wp-includes/`.

## Setup and versions

No new binary release or registry package is published by this documentation update. For historical reproduction, review the checked-in manifest and environment requirements first, use an isolated database, and keep production credentials out of the checkout. A dependency install is not proof that old integrations still work.
